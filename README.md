# Money Transfer System

Enterprise Banking Microservice - Capstone Project

## Project Overview
A production-grade digital money transfer microservice built progressively through 5 training modules:
- GIT (Version Control)
- Advanced Java (Domain Models)
- Spring Boot (REST APIs)
- Angular (Frontend UI)
- Snowflake (Analytics)

## Technology Stack
- **Backend**: Java 17, Spring Boot 3.x, MySQL
- **Frontend**: Angular 18+, TypeScript
- **Data Warehouse**: Snowflake
- **Version Control**: Git, GitHub

## Project Structure
```
money-transfer-system/
├── backend/          # Spring Boot application
├── frontend/         # Angular application
├── database/         # SQL scripts
├── snowflake/        # Data warehouse scripts
└── docs/             # Documentation
```
